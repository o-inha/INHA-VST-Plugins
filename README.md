# INHA VST3 Plugins Issue Tracker

This repository is the public issue tracker for [INHA VST plugins](https://inha.jp).

The plugin sources is proprietary and is not contained in this
repository.

Please use the Issues tab to report bugs, request features, or suggest
improvements.

If reporting a bug, please include:
- Plugin name and version
- DAW name and version
- Operating system name and version
- Step-by-step instructions what to do with the plugin to hear or see the bug
